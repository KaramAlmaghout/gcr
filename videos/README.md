# MuJoCo Videos

These MP4 files are the retained four-camera replays of the paper's
fewest-configuration solutions. Each recording includes the final settling
period used before measuring cable-shape error.

Retained source scenarios: 2, 5, 7, 8, 9, and 14. The benchmark and waypoint
exports cover all ten paper scenarios; only these six recordings were retained
in the final working archive.
